Git adalah Distributed Vesion Control System
Version Control -> helps you track and manage code changes over time.
Distributed -> Means that every developer's computer has a complete copy of the codebase, including its entire history of changes and information about who changed what and when, allowing you to get blame someone. Hopefully, people won't blame you.

Misal kamu punya project di sebuah folder di laptop kamu bernama `MyProject`. Nah, selama kamu berprogres, kamu mungkin kepikiran buat gak mau kehilangan project kamu itu, bisa aja gak sengaja dihapus kucing kamu misalnya. Terus kamu bikin copy dari project kamu itu, mulai dari `MyProject_v1`, `MyProject_v2`, `MyProject_v3`, dan seterusnya. Terus misal rekan kamu minta project kamu yang versi terbaru karena kalain bekerja secara tim. Terus kamu kasih lah file `MyProject_v3` kamu ke dia. Selagi dia ngerjain kerjaan dia di laptopnya, kamu ikut berprogres juga dan terciptalah `MyProject_v4`, terus tiba-tiba rekan kamu ngirim versi buatannya, misalnya `MyProject_v3_buatan_guweh`. Terus kamu bikin versi baru lagi dengan masukin perbahan dari temen kamu ke `MyProject_v4` dan terciptalah `MyProject_v5`. Terus di `MyProject_v5`, lah kok malah gak jalan lagi dan error kodenya? Terus kamu cek satu per satu kodenya buat nyari yang salah, apakah yang salah di bagianmu, aau di bagian temenmu? Terus kalau gini siapa yang tanggung jawab? Kelihatan gak rapi, bingugin, dan repot banget, kan? Nah, makanya di sini lah git muncul.
